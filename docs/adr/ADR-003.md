# ADR-003: Testcontainers para banco nos testes

Status: aceita
Data: 2026-10-29

## Contexto

Testes que dependem de constraint de exclusao, transacao e lock precisam de Postgres real.

## Alternativas

a) Banco em memoria (H2).
b) Postgres local.
c) Testcontainers.

## Decisao

Opcao c.

## Consequencias

Positivas: cada build sobe um Postgres 16 isolado. Garante que constraint de exclusao, extensao btree_gist e transacao funcionam como em producao.

Negativas: precisa de Docker no ambiente de teste. Build fica mais lento.

## Evidencia

BaseIntegracaoTest sobe um container por JVM. Pipeline do GitHub Actions tem Docker disponivel.

## Condicao de revisao

Se o ambiente de CI deixar de oferecer Docker.
