# ADR-002: Autenticacao JWT stateless

Status: aceita
Data: 2026-10-29

## Contexto

A aplicacao precisa de autenticacao por perfil sem manter estado no servidor.

## Alternativas

a) Sessao em memoria.
b) Sessao com Redis.
c) JWT stateless.

## Decisao

Opcao c, com jjwt 0.12.6.

## Consequencias

Positivas: sem estado no servidor, facilita escalar. Filtro unico valida token em toda requisicao. Perfis vem dentro do token.

Negativas: revogar token antes do vencimento exige lista negra. Nesta versao nao ha revogacao.

## Evidencia

JwtService, JwtFiltro e SecurityConfig. AutorizacaoPorPerfilTest cobre 401 sem token e 403 com perfil errado.

## Condicao de revisao

Se o sistema precisar de revogacao imediata de sessao.
